# Студия штор «СТРЕКОЗА»

Русскоязычный статический демосайт московской студии текстильного оформления. Для локального просмотра распакуйте проект и откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются.

## Обновление

- Страницы и контакты находятся в `index.html`, оформление в `styles.css`, услуги, тарифы, калькулятор и запись в `app.js`.
- Публикуемые фотографии добавляйте в `assets/` после согласования прав. В `portfolio.js` указывайте идентификатор, локальный путь, размеры, подпись, категорию и альтернативный текст. Категории формируются из списка фотографий автоматически.
- Для публикации на GitHub Pages выберите **Deploy from a branch → main → /(root)** в настройках нового репозитория. Сохранение изменений в `main` запускает обновление сайта. `index.html` должен быть в корне. Укажите абсолютный HTTPS-адрес `og:image` для превью.
- После изменения проверьте калькулятор, запись, редактирование заявки и галерею на мобильной и полноразмерной версиях.

## Данные и материалы

Оформление демонстрационное. Выбранное время — пожелание по московскому времени. Заявки и уменьшенные копии фотографий хранятся в LocalStorage текущего браузера. «Мои заявки» доступны в подвале сайта. Там можно просмотреть, отредактировать, отменить, экспортировать заявку или удалить все сохранённые данные.

Встроенный ImageGen создал две подписанные иллюстрации. Запрос для `assets/hero.jpg` — редакционный интерьерный кадр европейского салона с античной патиной, высокими окнами, драпировками цвета шампань и тёплым дневным светом. Запрос для `assets/textiles.jpg` — редакционный натюрморт из льна, бордового бархата и декоративного шнура на ореховом столе. `assets/social.jpg` подготовлен из обложки. Дворцовые референсы использованы для визуального направления. Шрифт Cormorant Garamond распространяется по SIL Open Font License 1.1, см. `assets/OFL-Cormorant.txt`.
